# Contributing to Mrclone.ai

Thanks for your interest in improving Mrclone.ai!

## Ways to contribute

- Report a reproducible bug
- Suggest a focused feature
- Improve documentation or accessibility
- Submit a fix or enhancement

## Before opening a pull request

1. Search existing issues to avoid duplicate work.
2. For larger changes, open an issue first to discuss the approach.
3. Keep changes focused and explain the user benefit.
4. Test the app in a modern browser.
5. Never commit API keys, passwords, private user data, or other secrets.

## Pull request checklist

- [ ] The change has a clear description.
- [ ] The app still opens and works locally.
- [ ] Relevant manual tests have been completed.
- [ ] Documentation is updated when behavior changes.
- [ ] No secrets or private data are included.

By contributing, you agree that your contributions are provided under the repository's MIT license.
